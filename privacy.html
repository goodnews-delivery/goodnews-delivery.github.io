개인정보처리방침

좋은 소식 배달부(이하 「서비스」)는 매일 따뜻한 국내 뉴스를 골라 유튜브, 인스타그램, 쓰레드에 게시하는 운영자 전용 도구입니다. 시행일: 2026년 10월 28일

1. 수집하는 정보

서비스는 일반 이용자의 개인정보를 수집하지 않습니다. 운영자 본인의 유튜브, 인스타그램, 쓰레드 계정에 게시하기 위해 각 플랫폼이 발급한 접근 토큰만 운영자의 컴퓨터에 저장합니다.

2. 이용 목적

접근 토큰은 운영자 계정에 영상, 이미지, 글을 업로드하고 게시 결과를 확인하는 용도로만 씁니다. Google 사용자 데이터는 YouTube 업로드 외의 목적으로 쓰지 않으며, 제3자에게 제공하거나 판매하지 않습니다. 서비스의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

3. 보관과 삭제

토큰은 운영자의 컴퓨터에만 보관하며 외부 서버로 보내지 않습니다. 운영자는 언제든 각 플랫폼의 계정 설정에서 연결을 해제해 접근 권한을 철회할 수 있습니다.
