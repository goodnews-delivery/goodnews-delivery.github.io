Privacy Policy / 개인정보처리방침

Good News Delivery (좋은 소식 배달부) uploader is a private tool used only by the owner of the YouTube channel @좋은소식배달부 to publish Shorts to that channel. Effective date: October 28, 2026.

1. Use of YouTube API Services

This tool uses YouTube API Services to upload videos to the owner's own YouTube channel (videos.insert) and to confirm the target channel (channels.list). By using this tool you agree to be bound by the YouTube Terms of Service. YouTube data is handled under the Google Privacy Policy.

2. Information we access, collect and store

The tool accesses only the owner's own Google account and YouTube channel, using the OAuth scopes youtube.upload and youtube.readonly. It stores one OAuth refresh token on the owner's computer. It does not collect, store or share any data of other users, does not use cookies, and does not track viewers.

3. How information is used and shared

The token is used only to upload videos the owner has approved and to confirm the upload went to the correct channel. It is never sent to any server other than Google's, never sold, and never shared with third parties.

4. Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, or on request to the contact below, the stored token is deleted from the owner's computer within 7 days. Uploaded videos can be deleted at any time in YouTube Studio.
